# Mission Control v0.4 — information architecture

The default screen answers one question: **What should Michael care about right now?**

## Layer 1 — NOW
One project, one next action, one reason, one primary link.

No metric wall. No portfolio grid. No filters.

Priority order is deterministic: needs human judgement → blocked → moving → setup-needed → next visible work.

## Layer 2 — NEXT UP
At most three additional projects. This is a queue, not a second dashboard.

## Layer 3 — EVERYTHING ELSE
Collapsed by default. All visible public projects remain accessible and are grouped by operational state. Information is hidden by hierarchy, never deleted.

## Layer 4 — SYSTEM DETAILS
Collapsed by default. Snapshot time, evidence scope, harness coverage, mode and public-safety limitations live here because they matter for trust but not for the founder's immediate decision.

## Design rule
Every new piece of information must earn placement in one of these four layers. If it does not change the next decision, it cannot enter Layer 1.
